Core Constraints

The 64 Limit

Maximum 64 short addresses (0-63) per bus. Beyond this, the bus must be split.

[00] [01] [02] ... [61] [62] [63]

Groups & Scenes

  • Max 16 Groups
  • Max 16 Scenes
  • 15-min commissioning timer
  • DT8 color support

Replacement Flow

Failed Ballast Recovery

  • Install new gear (shows as unassigned)
  • Discover only new gear (do not randomize bus)
  • Assign explicit OLD short address
  • Re-apply group/scene from saved config
  • Verify functionality
